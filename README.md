# DM Companion

Herramienta para Dungeon Masters de D&D 5e: bestiario, generador de botín y bandeja de dados.
Construida con React + Vite, datos de https://www.dnd5eapi.co/api/ y empaquetada para Android con CapacitorJS.

- **Web (Vercel):** https://dm-companion-pi.vercel.app
- **APK:** sección Releases de este repositorio (v1.0.0)

## Desarrollo
```bash
npm install
npm run dev
```
